# nkselove — сайт НКСЭ для Firebase Hosting

Этот репозиторий — собранная копия всего сайта для хостинга Firebase.
Адрес: **https://nkselove.web.app**

Структура полностью повторяет GitHub Pages, чтобы все ссылки работали
одинаково на обоих хостингах:

- `/` — меню (репозиторий `clashroalyskachat-glitch.github.io`)
- `/mypars/` — расписание (репозиторий `mypars`)
- `/mypars/library/` — библиотека

## Как это обновляется

1. Основные правки вносятся в исходные репозитории (меню, расписание, библиотека).
2. Workflow `.github/workflows/sync-and-deploy.yml` периодически забирает
   свежие файлы из обоих репозиториев и пересобирает этот сайт.
3. GitHub Pages продолжает работать как раньше —Firebase его не заменяет,
   а дублирует.

## Файлы

- `firebase.json` — настройки Firebase Hosting (публикуется корень репозитория).
- Папки `mypars/` — копия сайта расписания и библиотеки.
